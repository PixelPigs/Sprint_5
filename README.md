Тестирование сервиса Stellar Burgers

Тестовые данные и дополнительное задание находится в файле test_data.py
Фикстуры в файле conftest.py
Локаторы в файле locators.py

I) Форма Регистрации (https://stellarburgers.nomoreparties.site/register)

1.1 Проверяем что, значение поля Имя не пустое
    (Ввести Имя, Email, Пароль)
    Ожидаемый результат: Проверить, что значение не пустое (value != "")

1.2 Проверяем введенные данные в поле Email (веден формат логин@домен)
    (Ввести корректные Имя, Пароль, Email ввести только логин или только домен)
    Ожидаемый результат: Ошибка формы, регистрации не происходит

1.3 Проверяем уведомление об ошибке, если введен некорректный пароль
    (Ввести некорректные граничные значения: 0 и 5 символов)

1.4 1.1 Вводим корректные данные и проверяем, что регистрация прошла успешно
    (Ввести: Имя, логин, пароль)
    Ожидаемый результат: Переход на форму Вход


II) Форма Входа (https://stellarburgers.nomoreparties.site/login)

2.0 Проверяем переход на главную страницу после успешной Авторизации
    Авторизуемся с корректными данными, проверяем, что находимся на главной странице

2.1 На главной странице сайта перейти по кнопке Войти в аккаунт, ввести корректные данные, нажать Войти
    Ожидаемый результат: переход на страницу входа и успешная авторизация

2.2 На главной странице сайта перейти по кнопке Личный кабинет, ввести корректные данные, нажать Войти
    Ожидаемый результат: успешный переход на страницу входа и успешная авторизация

2.3 На форме регистрации перейти по кнопке Войти, ввести корректные данные, нажать Войти
    Ожидаемый результат: успешный переход на страницу входа и успешная авторизация

2.4 На форме Входа перейти в форму Восстановление пароля, клик по кнопке Войти ввести корректные данные, нажать Войти
    Ожидаемый результат: успешный переход на страницу входа и успешная авторизация


III) Переход в личный кабинет (https://stellarburgers.nomoreparties.site/account/profile)

3.1 Проверяем переход в личный кабинет
    Авторизация, переход в личный кабинет, проверяем корректный url

3.2 Проверяем переход из Личного кабинета в конструктор
    Авторизация, переход в личный кабинет, переходим в конструктор, проверяем корректный url

3.3 Проверяем из Личного кабинета по клику на Конструктор и на логотип

3.4 Проверяем Выход из Личного кабинета
    Авторизация, переход в личный кабинет, Выход из кабинета, проверяем url (перешли на страницу Входа)
